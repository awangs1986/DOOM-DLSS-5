# 简体中文语言包

`languages/zh-cn.ini` 使用 schema 1，提供当前已接入英文非空文本键的简体中文译文，涵盖退出确认、Messages 与 Options 提示、gamma 提示、快速存档/读档确认、全部物品拾取反馈，以及图形菜单状态和原因说明。快速存档和读档模板各保留一次 `{save_name}`；退出确认及通用确认仍使用实际按键 Y/N。SR（超分）与 NR（神经渲染增强）保持为独立功能术语；DLAA 载体创建成功、NR 复选框得到确认，以及 NR 在 GPU 上实际执行，是不同状态，相关译文分别表达。

可在启动时使用 `-lang zh-cn` 选择此语言包；使用 `-lang en` 可恢复内建英文。未指定 `-lang` 时，程序沿用已保存的语言选择；没有保存选择时使用英文。缺少文本键时会逐键回退到内建英文。语言包采用 UTF-8，并随包提供当前 93 个已接入键所需的 CJK 位图字形子集。英文及 ASCII 标点继续使用原 DOOM 字体；有效字体中的未收录码点显示一个 `?`。字体缺失、损坏或缺少译文所需字符时，启动会记录原因并整体回退内建英文。字体来源、许可、资源校验和生成方式见 [中文位图字形资源](chinese-font.md)。这不代表完整汉化或中文显示已通过 Windows 实机验收。

字体资源及菜单／HUD 的 UTF-8 消费者已经接入；Windows 最终集成构建与实际画面验收仍在进行，完成后记录实际显示证据与未迁移文本范围。
