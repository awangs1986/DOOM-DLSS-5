# #16: 15: 在菜单中开关 RT、超分和 DLSS5 并可靠回退

## Parent

https://github.com/awangs1986/DOOM-DLSS-5/issues/1

## What to build

玩家在“选项 → 图形设置”用三个开关控制光追、官方 DLSS 超分和项目 DLSS5／DLSSNR 神经渲染增强（NR）；返回游戏即可比较可用效果，选择能保存，实际状态及不可用／回退原因可见。门、透明及天空在组合中正确，某项失败仍能继续游戏。

## Acceptance criteria

- [ ] 游戏菜单提供光追（RT）、超分（官方 DLSS SR）、DLSS5／DLSSNR（NR）三个开关，支持原菜单键盘选择、切换和返回，不要求改启动参数或配置文件。
- [ ] RT 与 SR 独立控制并覆盖两者关闭、仅 SR、仅 RT、RT 加 SR；RT 总开关控制硬阴影及已配置材质反射，不用诊断视图替代。
- [ ] RT、SR、NR 分别保存请求并显示实际状态。DLSS5／DLSSNR 是项目的神经渲染增强模式，不定义为超分或 SR 加 DLAA；开启 NR 需真实后端加载、功能激活和执行证据，不能以 SR／DLAA 成功或 DLL 文件名代替。关闭 NR 不改写 RT／SR 请求。
- [ ] NR／SR 组合按具体后端契约及实测判断。关闭 SR 仅停止 SR；若 NR 后端确实要求 SR，保留 NR 请求并显示该组合不支持及原因，不把此依赖写成 NR 的通用定义。缺少 NR 后端或失败时停止实际 NR，保留成功的 RT／SR 或普通显示，重启或重新启用后可重新检查能力。
- [ ] 已支持的开关在同一进程内于安全帧边界生效，等待必要 GPU 使用结束并重置相关历史；反复开关可安全恢复。仅启动时能加载的可选依赖明确提示重启，不安装或注入系统组件。
- [ ] 保存菜单修改的图形偏好并在重启恢复；明确启动参数优先于保存值及模式默认值，启动覆盖不自动改写偏好，菜单主动修改保存并在本次生效。
- [ ] 菜单显示启用、关闭、不可用或回退及原因；DXR、官方 SR、实际 NR 后端分别判断，一个不可用不阻止其他可用功能，用户期望与实际状态有区别。
- [ ] RT 在线性合成后进入 SR，普通显示和 SR 显示同一套正确光追颜色。
- [ ] SR 初始化、创建或执行失败时保留成功合成的 RT 画面；RT 失败关闭 RT 并继续正常显示，菜单同步实际状态。
- [ ] 反射及阴影共享已验证的动态、透明和天空规则；门／平台变化会更新反射命中，切换清除相关历史。
- [ ] 菜单、武器、HUD、调试视图和 PNG 导出在各组合正常，无强制第三方 Swapper 依赖。
- [ ] RTX 实机通过真实菜单切换验收四种 RT／SR 组合、各组合下 NR 独立请求／后端支持限制／缺依赖回退、连续切换及退出重启；附画面、状态日志、GPU 阶段计时与显存，不承诺未实测帧率。未实际验证的 NR 明确标记；不能以 SR／DLAA 代替其验收。
