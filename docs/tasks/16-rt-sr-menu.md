# #16: 15: 在菜单中开关 RT、超分和 DLSS5 并可靠回退

## Parent

https://github.com/awangs1986/DOOM-DLSS-5/issues/1

## What to build

玩家在“选项 → 图形设置”用三个开关控制光追、官方 DLSS 超分和项目 DLSS5 路径；返回游戏即可比较可用效果，选择能保存，实际状态及不可用／回退原因可见。门、透明及天空在组合中正确，某项失败仍能继续游戏。

## Acceptance criteria

- [ ] 游戏菜单提供光追（RT）、超分（官方 DLSS SR）、DLSS5 路径三个开关，支持原菜单键盘选择、切换和返回，不要求改启动参数或配置文件。
- [ ] RT 与 SR 独立控制并覆盖两者关闭、仅 SR、仅 RT、RT 加 SR；RT 总开关控制硬阴影及已配置材质反射，不用诊断视图替代。
- [ ] DLSS5 关闭使用普通官方 SR；开启只请求项目已实现且依赖真实可用的增强路径（当前 SR 加 DLAA）。菜单区分用户选择与实际运行功能，不由文件名或 DLL 版本推断全部 DLSS 5／Neural Rendering 能力。
- [ ] 超分关闭时不执行 SR／DLSS5 增强，菜单提示“需启用超分”并保留增强偏好；重新开启超分后重新检查能力。缺少可选扩展或增强失败时回退 SR 并显示原因。
- [ ] 已支持的开关在同一进程内于安全帧边界生效，等待必要 GPU 使用结束并重置相关历史；反复开关可安全恢复。仅启动时能加载的可选依赖明确提示重启，不安装或注入系统组件。
- [ ] 保存菜单修改的图形偏好并在重启恢复；明确启动参数优先于保存值及模式默认值，启动覆盖不自动改写偏好，菜单主动修改保存并在本次生效。
- [ ] 菜单显示启用、关闭、不可用或回退及原因；DXR、NGX、可选增强分别判断，一个不可用不阻止其他可用功能，用户期望与实际状态有区别。
- [ ] RT 在线性合成后进入 SR，普通显示和 SR 显示同一套正确光追颜色。
- [ ] SR 初始化、创建或执行失败时保留成功合成的 RT 画面；RT 失败关闭 RT 并继续正常显示，菜单同步实际状态。
- [ ] 反射及阴影共享已验证的动态、透明和天空规则；门／平台变化会更新反射命中，切换清除相关历史。
- [ ] 菜单、武器、HUD、调试视图和 PNG 导出在各组合正常，无强制第三方 Swapper 依赖。
- [ ] RTX 实机通过真实菜单切换验收四种 RT／SR 组合、DLSS5 开关／缺依赖回退、连续切换及退出重启；附画面、状态日志、GPU 阶段计时与显存，不承诺未实测帧率。无法验证的增强路径明确标记。
