## Acceptance criteria

- [ ] 干净构建可部署正确官方运行库、DXR 着色器、示例材质／光源及语言资源，启动不依赖工作目录。
- [ ] “选项 → 图形设置”入口、光追／超分／DLSS5 项、开关值、需启用超分、不可用／回退原因及需重启提示使用稳定语言键；英文默认和示例包均可操作，缺键回退英文，坏包整体回退，长提示安全显示，说明字体及未迁移文本限制。
- [ ] 用真实键盘菜单操作验收原版、SR、硬阴影、阴影加反射、RT 加 SR 和 DLSS5 路径选择，不仅用命令行启动代替；实际画面、菜单状态、运行日志与导出一致。
- [ ] 覆盖超分关闭时增强停用、重新启用、反复切换、退出重启恢复偏好、启动参数覆盖及菜单主动修改；确认相关历史重置和 UI／武器／HUD 正常。
- [ ] 验收 DXR／NGX 能力不可用、缺失运行库、缺少可选扩展及初始化／创建／执行失败；原因可见且回退可继续游戏，SR 失败保留 RT 颜色。没有真实可选依赖时明确增强路径未验证，不伪造加载。
- [ ] 验收换关、读档、传送、门／平台、栅栏／天空、菜单／武器／HUD、长文本及坏包／缺键回退；固定 demo 仍用于同时间线图像比较。
- [ ] 交付实际版本、硬件／工具链要求、菜单操作与设置优先级、实际功能与 DLSS5 标签的区别、各阶段耗时、显存、关键帧与备份恢复操作；未通过项明确列出。
- [ ] 维持首版范围：不包含完整质量档位、Frame Generation、sprite 光追或中文字体。
